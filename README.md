# TaskManager V2

TaskManager V2 is a console-based task management application developed in Java.

This project was created to practice object-oriented programming, layered architecture, JDBC, MySQL and the Repository Pattern.

## Features

- Create tasks
- View all tasks
- Edit tasks
- Complete tasks
- Delete tasks
- Search tasks
- Store data in MySQL

## Technologies

- Java 25
- Maven
- MySQL 8
- JDBC
- IntelliJ IDEA

## Project Structure

```

```
